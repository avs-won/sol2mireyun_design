# 미래연 그룹 홈페이지 — 리뉴얼 (FROM INVENTION TO VALUE)

## 내 컴퓨터에서 열어보기

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전 설치 (처음 한 번만)
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npm run dev
   ```
3. 브라우저에서 **http://localhost:3000** 접속

배포용 확인은 `npm run build` 후 `npm run start`.

## 콘셉트 — "명세서 (The Specification)"

특허 도면의 시각 문법을 사이트 전체의 디자인 언어로 썼습니다.
분해도 · 참조번호와 지시선 · `FIG.` 표기 · 해칭 · 치수선 · 【0001】 문단번호.
색은 기존 브랜드의 네이비(#1B2B45)와 브론즈(#8A6A45)를 계승한 **잉크 네이비 / 웜 페이퍼 / 브론즈** 3색입니다.

| 섹션 | 장면 |
|---|---|
| 01 첫 화면 | **FIG. 1 분해도** — 네 장의 판(발명 · 권리화 · 기술이전 · 자금)이 그려지고 분해되며 번호가 붙음. 스크롤하면 하나로 조립, 마우스에 깊이별로 반응 |
| 02 그룹 소개 | 교정선이 지나가며 드러나는 선언문, 해칭된 "Sol**2**", 줄기에서 뻗는 3개 법인 조직도, 부품표형 전문 인력 구성 |
| 03 서비스 | 6개 서비스 선택형 도면 시트 (데스크톱: 목록 + 시트 / 모바일: 아코디언) |
| 04 가치 설계 | **시그니처 고정 장면** — 하나의 판이 INVENT → PROTECT → CONNECT → GROW로 변형. 모바일은 도면이 위에 붙고 글이 지나가는 방식 |
| 05 9단계 로드맵 | **계단 단면도** — 커서가 9단계를 오르며 지원 구간(치수선)이 채워짐. 모바일은 세로 레일 |
| 06 전략 보고서 | 같은 점들이 Macro → Micro → Tower → Patrol 구도로 재배열되는 분석 개념도 |
| 07 수행 실적 | 굴러 멈추는 계수기(27 · 37 · 8건) + 실적 목록 72건 전체 (분류 필터) |
| 08 대표 변리사 | 공학과 법률, 두 선이 만나는 경력 도식 + 학력 · 경력 전체 |
| 09 상담 문의 | "다음 도면은 귀사의 기술입니다." — 작성 예정 도면 + 실제 문의 폼 |

## 문의 폼 연결 (배포 전 필수)

기존 사이트와 같은 방식(`/api/contact` + Resend)입니다. 배포 환경에 아래 값을 넣어야 메일이 발송됩니다.
`.env.example` 참고.

- `RESEND_API_KEY` — Resend API 키
- `CONTACT_FROM_EMAIL` — Resend에서 인증한 도메인의 보내는 주소
- `CONTACT_TO_EMAIL` — 받는 주소 (비우면 mayjo0510@gmail.com)

키가 없으면 폼은 "지금은 온라인 접수를 받을 수 없습니다"와 함께 전화 · 이메일을 안내합니다. (가짜 성공 메시지를 띄우지 않습니다.)

## 기술

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- GSAP 3.15 + ScrollTrigger · SplitText, Lenis(부드러운 스크롤)
- 도면은 전부 직접 그린 SVG (Three.js · WebGL 미사용)
- 글꼴: Pretendard(본문 · 제목), Archivo(영문 디스플레이), IBM Plex Mono(도면 표기)
- "동작 줄이기" 설정 사용자에게는 고정 장면 · 부드러운 스크롤 없이 완성된 도면을 보여 줍니다.
