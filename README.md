# 미래연 그룹 홈페이지 — 디자인 시안 v1

## 내 컴퓨터에서 열어보기

1. **Node.js 설치** (처음 한 번만)
   [nodejs.org](https://nodejs.org)에서 **LTS** 버전을 받아 설치합니다.
2. **이 폴더에서 터미널 열기**
   - Windows: 폴더 빈 곳에서 `Shift` + 마우스 오른쪽 클릭 → "터미널에서 열기"
   - Mac: 폴더를 터미널 앱 아이콘 위로 끌어다 놓기
3. **실행**
   ```bash
   npm run dev
   ```
4. 브라우저에서 **http://localhost:5173** 을 엽니다.

- 따로 설치할 것(`npm install`)은 없습니다.
- 파일을 고치고 저장하면 브라우저가 자동으로 새로고침됩니다.
- 끄려면 터미널에서 `Ctrl` + `C`.
- 5173번 포트를 이미 쓰고 있다면: `PORT=5174 npm run dev`
  (Windows PowerShell은 `$env:PORT=5174; npm run dev`)

## 폴더 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 내용 (문구 수정은 여기서) |
| `css/style.css` | 디자인 (색, 글꼴, 배치) |
| `js/main.js` | 애니메이션과 동작 |
| `dev-server.mjs` | 내 컴퓨터에서 실행할 때만 쓰는 서버. 배포에는 영향 없음 |

## 시안에 들어간 것

컨셉은 **"하루의 빛"**입니다. 그룹 이름의 Sol(태양)과 2(그림자)를 화면 전체에 풀었습니다.

1. **첫 화면 — 새벽**: 수평선 위로 해가 떠오르고 바다에 빛이 일렁입니다. 스크롤하면 해가 높이 오르며 한낮으로 밝아집니다.
2. **그룹 소개 — 한낮**: 작은 해가 하늘을 가로지르면, 큰 글자의 그림자가 해 반대쪽으로 따라 움직입니다. ("그림자처럼 늘 곁에서")
3. **9단계 사업화 로드맵**: 화면이 멈춘 채로 스크롤하면 해가 1단계부터 9단계까지 지나가며 하나씩 밝혀집니다. 아래 지원 구간도 해를 따라 채워집니다. 모바일에서는 세로형으로 바뀝니다.
4. **상담 문의 — 노을**: 해가 수평선으로 내려앉으며 마무리합니다.

서비스, IP 자금설계, 전략 보고서, 실적, 대표 변리사 섹션과 문의 폼은 본 작업에서 이어집니다.
메뉴에서 아직 없는 섹션을 누르면 "본 작업에서 추가됩니다" 안내가 뜹니다.

## 사용한 기술

- 순수 HTML / CSS / JavaScript — 빌드 과정 없이 지금 사이트처럼 그대로 배포할 수 있습니다.
- [GSAP](https://gsap.com) + ScrollTrigger: 스크롤 애니메이션 (무료)
- [Lenis](https://lenis.darkroom.engineering): 부드러운 스크롤
- 글꼴: Hahmlet(제목), Pretendard(본문)
- 위 라이브러리와 글꼴은 CDN에서 불러옵니다. (인터넷 연결 필요)
- 운영체제에서 "동작 줄이기"를 켠 사용자에게는 애니메이션 없이 보여줍니다.

## 배포 전에 확인할 것

- [ ] `index.html`의 `<meta name="robots" content="noindex, nofollow">`는 시안을 검색엔진에 숨기려고 넣은 것입니다. **실제 배포 때 삭제**
- [ ] 로고는 임시 텍스트 로고입니다. 원본 로고 파일을 받으면 교체
- [ ] 로드맵의 "원천 기술 단계 / 상용화 기술 개발 단계" 구간을 1–5단계 / 6–9단계로 나눴습니다. 기존 사이트 그림을 보고 추정한 것이라 확인 필요
- [ ] 문의 폼은 기존 사이트의 폼(`/api/contact`)을 그대로 연결할 예정입니다. 로컬에서는 메일 발송이 동작하지 않습니다
