# 미래연 그룹 홈페이지 리뉴얼 — 시안 모음

국제특허법률사무소 미래연 · ㈜솔투미래연 홈페이지 리뉴얼 작업 폴더입니다.
**시안 v2 · v3 · v4가 이 폴더 하나(Next.js 앱 하나)에 모두 들어 있습니다.** 시안마다 폴더를 따로 두지 않습니다.

## 내 컴퓨터에서 열어보기

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전 설치 (처음 한 번만)
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npm run dev
   ```
3. 브라우저에서 **http://localhost:3000** 접속 → 시안 목록에서 고르기

| 주소 | 내용 |
|---|---|
| `/` | 시안 목록 (검토용, 검색 노출 안 함) |
| `/v4` | **Seal — 권리가 되는 순간** (시네마틱, 최신) |
| `/v3` | Editorial Swiss — 신뢰와 권위 (라이트, 움직임 최소) |
| `/v2` | 명세서 — FROM INVENTION TO VALUE (특허 도면 콘셉트) |

모든 시안 화면 아래 가운데에 **시안 전환 버튼**(목록 · v2 · v3 · v4)이 떠 있습니다. 정식 오픈 때는 고른 시안 하나만 `/`에 연결하고 이 버튼을 뺍니다.

## 폴더 구조

| 위치 | 내용 |
|---|---|
| `src/content/` | **모든 문구와 사실 정보 — 세 시안이 함께 씀** (문구 수정은 여기서 한 번만). 실적 목록은 `results.source.json` |
| `src/lib/drafts.ts` | 시안 목록 (시안 카드 · 전환 버튼이 함께 읽음) |
| `src/components/DraftSwitcher.tsx` | 하단 시안 전환 버튼 |
| `src/app/(hub)/` | `/` 시안 목록 화면 |
| `src/app/(v2)/` · `src/drafts/v2/` | v2 레이아웃 · 스타일(`v2.css`) / 화면 · 모션 |
| `src/app/(v3)/` · `src/drafts/v3/` | v3 — 디자인 기준은 `design-system/mireyun-v3/MASTER.md` |
| `src/app/(v4)/` · `src/drafts/v4/` | v4 — 디자인 토큰은 `src/app/(v4)/v4.css` 맨 위 |
| `src/app/api/contact/route.ts` | 문의 폼 → 메일 발송 (세 시안 공용) |
| `src/app/global-not-found.tsx` | 없는 주소용 404 |

시안마다 **루트 레이아웃이 따로**(`(v2)/layout.tsx` 등) 있어서 글꼴 · 색 · 모션 라이브러리가 서로 섞이지 않습니다.
각 시안의 CSS는 자기 폴더만 훑도록(`@source`) 묶어 두었습니다. 시안 사이를 오가면 페이지가 새로 열립니다.

### 새 시안을 추가하려면

1. `src/app/(v5)/layout.tsx` · `src/app/(v5)/v5.css` · `src/app/(v5)/v5/page.tsx`
2. 화면 코드는 `src/drafts/v5/`
3. `src/lib/drafts.ts`에 한 줄 추가 → 목록과 전환 버튼에 자동으로 나타남

## v4 "Seal" — 콘셉트

`ui-ux-pro-max` 스킬(법률 · IP 업종, 모션 9/10)의 추천을 바탕으로, **첫 화면 3초 안에 '무엇을 하는 곳인지'**가 읽히도록 설계했습니다.

- **첫 화면**: "특허 출원부터 자금 조달까지, 한 팀이 끝까지." + 주요 업무 4개 + 상담 · 전화 버튼. 오른쪽에서는 빛 입자가 **전구(발명) → 방패(권리화) → 연결망(기술이전) → 성장 막대(자금)** 로 모양을 바꾸며 같은 흐름을 그림으로 보여 줍니다.
- **색**: 잉크(#070B14) · 아이보리(#ECE5D6) · 골드(#D4AF6A, 권리의 '인장'). 본문 대비 15:1, 보조 글자 7.6:1
- **글꼴**: Pretendard(한글) · Instrument Serif 이탤릭(영문 · 숫자) · IBM Plex Mono(표기)
- **모션**: 첫 진입 막 열림 · 줄 단위 마스크 등장 · 금빛 광택 · 입자 모핑과 인장 파동(Canvas) · 가로로 흐르는 고정 장면(4단계) · 스크롤 속도에 따라 기우는 실적 띠 · 단어별로 밝아지는 대표 변리사 선언문 · 글자가 금빛으로 차오르는 상담 문구
- **접근성**: "동작 줄이기" 설정에서는 고정 장면 · 입자 움직임 · 부드러운 스크롤 없이 완성된 화면을 보여 줍니다. 스크립트가 3초 안에 시작되지 않으면 숨겨 둔 요소를 모두 드러냅니다. 모든 버튼 44px 이상, 키보드 초점 표시, 탭 목록 화살표 키 이동

| 순서 | 섹션 |
|---|---|
| 01 첫 화면 | 헤드라인 · 주요 업무 · 입자 장면 · 지정/선정 이력 띠 |

## 문의 폼 연결 (배포 전 필수)

기존 사이트와 같은 방식(`/api/contact` + Resend)입니다. 배포 환경에 아래 값을 넣어야 메일이 발송됩니다. `.env.example` 참고.

- `RESEND_API_KEY` — Resend API 키
- `CONTACT_FROM_EMAIL` — Resend에서 인증한 도메인의 보내는 주소
- `CONTACT_TO_EMAIL` — 받는 주소 (비우면 mayjo0510@gmail.com)

키가 없으면 폼은 "지금은 온라인 접수를 받을 수 없습니다"와 함께 전화 · 이메일을 안내합니다. (가짜 성공 메시지를 띄우지 않습니다.)

## 기술

- Next.js 16 (App Router, 시안별 루트 레이아웃) · React 19 · TypeScript · Tailwind CSS 4
- GSAP 3.15 (ScrollTrigger · SplitText) + Lenis — v2 · v4
- 그림은 전부 직접 그린 SVG / Canvas 2D (WebGL · 외부 이미지 없음)
